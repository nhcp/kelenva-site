Deployed a 3-service Node.js microservices app plus React frontend to Amazon EKS,
with Terraform-managed infrastructure and GitHub Actions handling build and deploy.

Covers service-to-service communication, MongoDB persistence, ingress routing,
and a full CI/CD pipeline from commit to cluster.
